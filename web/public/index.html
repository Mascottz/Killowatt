The policy that trips it

cue, validated before it ships; money in integer cents 
acme: #Policy & {
  account:           "acme-prod"
  daily_limit_cents: 250_00   // $250.00 a day
  hourly_limit_cents: 60_00   // $60.00 an hour
  burst: {
    window_seconds:  600
    limit_cents:     40_00    // retry storms land here first
  }
  action:            "hard_stop"
  exempt:            ["rds-prod-backups"]
}

Three windows, in order.

burst catches loops within minutes; the hourly limit catches slow leaks; the daily limit is the last line. exempt services keep running through a trip, because backups should never take the blame.
