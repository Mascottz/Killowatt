# Paste this into a fresh session, verbatim

Start a new public repo on my github (account Mascottz). something that
blows people's minds when they land on it; not a toy, a world class repo
that reads like i built every line, because my github needs to look like
a portfolio now.

Before any building, pitch me five ideas, each with a real narrative
hook; the kind of opening line that makes a stranger stop scrolling.
i pick one, then we build it to the rules below.

The rules, all of them, no exceptions;

- Every word in the repo is mine. lowercase, casual, direct, first
  person; readme, docs, commit messages, issue bodies, launch copy. no
  second person, no third person, no "the user", no "you". no em dashes
  anywhere; use ; or , or an arrow where a break is needed; a plain dash
  only inside a hyphenated word.
- Polyglot with uncommon languages; at least two, none of them the
  obvious default for its job, each one justified in the architecture
  doc before i approve the stack.
- If it has a ui; calm, elegant, demure. serif display type, monospace
  for numbers, a color system nobody else is using, no plain rectangle
  section cards, no generic pills. the design doc comes first, before
  any screen exists.
- World class means provable. tests pinned in every language, ci
  running all of them, architecture and design docs, contributing and
  security docs, an honest "what is real vs what is demo" section, and
  a demo a stranger runs in under five minutes with zero accounts.
- Github gets dressed before launch; description, about ten topics, a
  social preview card drawn in the repo's own design system, a v0.1.0
  release, good first issues opened ahead of time, and a launch kit in
  the repo; hn copy and a blog post, same voice.
- Money is integer cents if money ever appears; floats never touch it.
- Commits are small, in my voice, pushed to main as we go. toolchains
  live in the cache so the repo stays small. a token i paste never gets
  stored; it lives for the push and dies after.
- I will say "next" a lot. keep choosing the best next step yourself
  and keep the pipeline moving; ask me only for the idea pick and for
  credentials, nothing else.

The bar is simple; a stranger opens it, reads two paragraphs, runs one
command, and stars it before they can explain why.
